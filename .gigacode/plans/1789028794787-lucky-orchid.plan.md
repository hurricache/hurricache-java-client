## Queue API Constraints

| Method | Supported? | Notes                                                   |
|--------|-----------|---------------------------------------------------------|
| `createQueue` | ✅ | Empty or with initial data                              |
| `streamQueue` | ❌ | Not supported                                           |
| `getAndRemoveFront` | ✅ | Pop front                                               |
| `getFront` / `getHead` | ✅ | Peek front/head                                         |
| `getTail` | ✅ | Peek tail                                               |
| `getAndRemoveTail` | ✅ | Pop back                                                |
| `addElementToTail` | ✅ | Push back                                               |
| `addElementToHead` | ❌ | Not supported (queue is FIFO)                           |
| `removeHead` | ✅ | Pop front without return                                |
| `removeTail` | ❌ | Not supported                                           |
| `getElementAtPosition` | ❌ | Returns INTERNAL "Key not found or type is not correct" |
| `getAndRemoveElementAtPosition` | ❌ | Returns INTERNAL                                        |
| `addElementToPosition` | ❌ | Returns INTERNAL                                        |
| `removeElementAtPosition` | ❌ | Returns INTERNAL                                        |
| `addElementToPositionBefore` | ❌ | Returns INTERNAL                                        |
| `addElementToPositionAfter` | ❌ | Returns INTERNAL                                        |
| `remove` | ✅ | Delete queue                                            |
| `lockObject` / `unlockObject` | ✅ | Lock types supported                                    |
| `setTtl` / `getTtl` | ✅ | TTL supported                                           |
| `getSize` | ❌ | Size not supported                                      |

**Unsupported methods error:** `Status.Code.INTERNAL` with message "Key not found or type is not correct"

**Empty queue behavior:**
- `getHead` returns empty Payload (empty byte array)
- `removeHead` does NOT throw, returns normally

## Key Differences from List/Vector Tests

1. **No streamQueue** — queue doesn't support streaming
2. **No positional operations** — getElementAtPosition, addElementToPosition, etc. are not supported
3. **No addElementToHead/removeHead** — queue is FIFO, only tail operations for adding
4. **Empty queue returns empty Payload** — not an error for getHead/getAndRemoveFront
5. **Unsupported methods return Status.Code.INTERNAL** — not NOT_FOUND
6. **removeHead doesn't throw on empty queue** — returns normally
