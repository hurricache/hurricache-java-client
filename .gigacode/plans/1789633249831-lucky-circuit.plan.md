## Cluster Test Conventions (from existing tests)

Based on analysis of `AtomicOperationsTest`, `HashMapOperationsTest`, `VectorOperationsTest`, `ListOperationsTest`, `QueueOperationsTest`:

| Convention | Pattern |
|------------|---------|
| **KeyHintData** | Always use KeyHintData returned by create method |
| **No setMode during create** | `client.createXxx(...)` — never `client.setMode(Mode.MASTER).createXxx(...)` |
| **Small object replication wait** | `Thread.sleep(500)` after creation |
| **Large object replication wait** | `Thread.sleep(1500)` for 1500 elements × 8KB |
| **Write on MASTER → verify MASTER → verify BACKUP** | Write on MASTER, immediate verify on MASTER, then `Thread.sleep(300)` then verify on BACKUP |
| **Write on BACKUP → verify BACKUP → verify MASTER** | Write on BACKUP, immediate verify on BACKUP, then `Thread.sleep(300)` then verify on MASTER |
| **TTL set on MASTER → verify on MASTER → verify BACKUP** | Same pattern with replication delay |
| **TTL set on BACKUP → verify on BACKUP → verify MASTER** | Same pattern with replication delay |
| **Lock on MASTER → verify on MASTER → verify BACKUP** | Same pattern with replication delay |
| **Lock on BACKUP → verify on BACKUP → verify MASTER** | Same pattern with replication delay |
| **TTL expiration** | Set short TTL (1-2s), wait for expiry, verify NOT_FOUND on both nodes |
| **Lock expiration** | Set short TTL lock (2s), wait for expiry, verify accessible on both nodes |

## 3. Cluster Conventions Checklist (for all new/enhanced tests)

Every test MUST follow this pattern:

```java
// 1. Create WITHOUT setMode
KeyHintData hint = client.createXxx(key, data).get();

// 2. Replication wait
if (largeObject) {
    Thread.sleep(1000);  // or 1500 for very large
} else {
    Thread.sleep(500);
}

// 3. Write on MASTER → verify MASTER (no delay)
client.setMode(Mode.MASTER).writeOperation(...).get();
client.setMode(Mode.MASTER).verifyOperation(...).get();

// 4. Replication delay → verify BACKUP
Thread.sleep(300);
client.setMode(Mode.BACKUP).verifyOperation(...).get();

// 5. Write on BACKUP → verify BACKUP (no delay)
client.setMode(Mode.BACKUP).writeOperation(...).get();
client.setMode(Mode.BACKUP).verifyOperation(...).get();

// 6. Replication delay → verify MASTER
Thread.sleep(300);
client.setMode(Mode.MASTER).verifyOperation(...).get();
```

**TTL tests:**
```java
// Set TTL on MASTER → verify on MASTER → sleep 300 → verify on BACKUP
client.setMode(Mode.MASTER).setTtl(key, hint, ttl).get();
client.setMode(Mode.MASTER).getTtl(key, hint).get();
Thread.sleep(300);
client.setMode(Mode.BACKUP).getTtl(key, hint).get();

// TTL expiration: set short TTL → wait → verify NOT_FOUND on both nodes
```

**Lock tests:**
```java
// Lock on MASTER → verify on MASTER → sleep 300 → verify on BACKUP
client.setMode(Mode.MASTER).lockObject(key, hint, type, ownerId, duration).get();
// verify operations on MASTER
Thread.sleep(300);
// verify on BACKUP

// Lock expiration: set 2s TTL lock → wait 3s → verify accessible on both nodes
```

## 5. Validation Criteria

Before merging, each new/enhanced test MUST pass:

- [ ] Uses `KeyHintData` from create method
- [ ] Does NOT use `setMode` during create
- [ ] Has replication wait after creation (500ms small / 1000-1500ms large)
- [ ] Verifies write on same node immediately (no delay)
- [ ] Verifies write on neighbor node after `Thread.sleep(300)`
- [ ] Tests both MASTER and BACKUP write scenarios
- [ ] TTL tests verify on both nodes
- [ ] Lock tests verify on both nodes
- [ ] Lock expiration tested on both MASTER and BACKUP
- [ ] TTL expiration tested on both MASTER and BACKUP
