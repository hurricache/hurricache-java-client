## Cluster Test Conventions (MUST follow)

```java
// 1. Create WITHOUT setMode
KeyHintData hint = client.createXxx(key, data).get();

// 2. Replication wait: 500ms small / 1000-1500ms large
Thread.sleep(500); // or 1500 for 1500-element containers

// 3. Write on MASTER → verify MASTER (immediate, no delay)
client.setMode(Mode.MASTER).writeOp(...).get();
client.setMode(Mode.MASTER).verifyOp(...).get();

// 4. Replication delay → verify BACKUP
Thread.sleep(300);
client.setMode(Mode.BACKUP).verifyOp(...).get();

// 5. Write on BACKUP → verify BACKUP (immediate)
client.setMode(Mode.BACKUP).writeOp(...).get();
client.setMode(Mode.BACKUP).verifyOp(...).get();

// 6. Replication delay → verify MASTER
Thread.sleep(300);
client.setMode(Mode.MASTER).verifyOp(...).get();
```
