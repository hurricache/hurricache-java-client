## Справочные маппинги утилит

### `KeyValueUtils.createUnorderedKey(byte[] key, KeyHintData hint, int clientId, int compressionThreshold) → Key.Builder`
| Поле Key | Источник |
|----------|----------|
| `payload` | `KeyBinaryPayload(payload=key_bytes, size=key.length)` |
| `keyHint` | `KeyHint(strongHash=hint.strongHash(), weekHash=hint.weekHash())` |
| `clientId` | `clientId` |

### `KeyValueUtils.createUnorderedValue(byte[] value, Duration ttl, Integer compressionThreshold) → Value.Builder`
| Поле Value | Источник |
|------------|----------|
| `value` | `BinaryPayload(payload=value_bytes, size=value.length)` |
| `ttl` | `System.currentTimeMillis() + ttl.toMillis()` |

### `KeyValueUtils.createOrderedValue(byte[] value, long order, Duration ttl, int compressionThreshold) → OrderedValue.Builder`
| Поле OrderedValue | Источник |
|-------------------|----------|
| `value` | `BinaryPayload(payload=value_bytes, size=value.length)` |
| `order` | `order` |
| `ttl` | `System.currentTimeMillis() + ttl.toMillis()` |

### `CompressionUtils.compressIfNeeded(byte[] value, Integer threshold) → Value.Builder`
Сжимает значение через LZ4 если `value.length > threshold`, заполняя `CompressedInfo`.

## Сводка маппингов возвращаемых типов

| Proto Response | Java Type | Observer / Extractor |
|----------------|-----------|---------------------|
| `BoolResponse.value` | `Boolean` | `CompletableFutureObserver<>(future, BoolResponse::getValue)` |
| `TtlResponse.ttl - System.currentTimeMillis()` | `Long` | ручной маппинг в `getTtl()` |
| `KeyHintResponse.keyHint` | `KeyHintData` | `CompletableFutureObserver<>(future, r → KeyHintData.of(r.keyHint.strongHash, r.keyHint.weekHash))` |
| `ValueResponse.value_unordered.value.payload` (decompressed) | `byte[]` | `DecompressingObserver(future)` |
| `UpdateValueResponse.result` | `Boolean` | `DecompressingObserver.Update(future)` |
| `IntResponse.size` | `Integer` | `CompletableFutureObserver<>(future, IntResponse::getSize)` |
| `AtomicValue.val` | `Long` | `CompletableFutureObserver<>(future, AtomicValue::getVal)` |
| `AtomicCasRes` | `AtomicCasRes` | `CompletableFutureObserver<>(future)` (без маппинга) |
| `LockResponse.result` / `UnlockResponse.result` | `LockStatus` | `CompletableFutureObserver<>(future, LockResponse::getResult)` / `UnlockResponse::getResult` |
| `stream BatchValueResponse` | `List<Payload>`, `Map<Payload,Payload>`, `List<OrderedPayload>`, `Map<OrderedPayload,Payload>` | `StreamBatchUnorderedObserver`, `StreamBatchMapObserver`, `StreamBatchOrderedObserver`, `StreamBatchOrderedMapObserver` |
