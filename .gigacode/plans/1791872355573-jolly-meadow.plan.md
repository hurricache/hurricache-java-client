# План адаптации клиента и тестов к новому протоколу HurriCache

## Сводка изменений протокола

1. **BinaryPayload**: `bytes payload` → `oneof data { bytes payload, int64 intPayload, double doublePayload }`
2. **ValueType**: новый enum `AUTO/BYTES/INT/DOUBLE`, добавлен в `Value` (field 5) и `OrderedValue` (field 6)
3. **Atomic operations**: `AtomicCreate`/`AtomicCas` удалены. `atomicExchange/Add/Sub/Or/And/Xor` принимают `CreateRequest` и возвращают `ValueResponse`. `atomicCompareAndSet` принимает `CreateRequest`, `AtomicCasRes.expected` → `ValueResponse`
4. **Удалённые RPC**: `atomicCreate`, `atomicStore`, `atomicLoad`, `atomicLoadAndDelete`, `streamReplication`
5. **Переименования RPC**: `existKeyInContainer` → `existInContainerByKey`, `getValueInContainer` → `getValueInContainerByKey`, `removeInContainer` → `removeInContainerByKey`, `removeFromContainerByKeyValue` → `deleteFromContainerByKeyValue`, `getAndRemoveFront` → `getAndDeleteHead`, `getAndRemoveTail` → `getAndDeleteTail`, `removeHead` → `deleteHead`, `removeTail` → `deleteTail`, `removeElementAtPosition` → `deleteElementAtPosition`, `getElementInRange` → `getElementsInRange`
6. **Return type changes**: `removeHead/removeTail/removeElementAtPosition` возвращают `IntResponse` (Integer) вместо `BoolResponse` (Boolean)
7. **Variant return type**: все методы, возвращавшие `byte[]` или `Payload`, теперь возвращают `Variant` (int/double/byte[]), тип определяется по `ValueType` в `Value`/`OrderedValue`

## Фаза 0: Создание Variant

**Новый файл**: `src/main/java/com/hurricache/client/intf/Variant.java`

```java
package com.hurricache.client.intf;

/**
 * Variant — универсальный тип возврата, может содержать int, double или byte[].
 * Тип определяется на основе ValueType из протокола.
 */
public final class Variant {
    public enum Type { NONE, BYTES, INT, DOUBLE }
    
    private final Type type;
    private final byte[] bytesValue;
    private final long intValue;
    private final double doubleValue;
    
    private Variant(Type type, byte[] bytesValue, long intValue, double doubleValue) {
        this.type = type;
        this.bytesValue = bytesValue;
        this.intValue = intValue;
        this.doubleValue = doubleValue;
    }
    
    public static Variant ofBytes(byte[] value) {
        return new Variant(Type.BYTES, value, 0L, 0.0);
    }
    
    public static Variant ofInt(long value) {
        return new Variant(Type.INT, null, value, 0.0);
    }
    
    public static Variant ofDouble(double value) {
        return new Variant(Type.DOUBLE, null, 0L, value);
    }
    
    public static Variant none() {
        return new Variant(Type.NONE, null, 0L, 0.0);
    }
    
    public Type type() { return type; }
    public boolean isNone() { return type == Type.NONE; }
    public boolean isBytes() { return type == Type.BYTES; }
    public boolean isInt() { return type == Type.INT; }
    public boolean isDouble() { return type == Type.DOUBLE; }
    
    public byte[] bytesValue() { return bytesValue; }
    public long intValue() { return intValue; }
    public double doubleValue() { return doubleValue; }
    
    // Convenience cast methods
    public Number numberValue() {
        return (type == Type.DOUBLE) ? doubleValue : (Number) intValue;
    }
    
    public byte[] requireBytes() {
        if (type != Type.BYTES) throw new IllegalStateException("Expected BYTES, got " + type);
        return bytesValue;
    }
    
    public long requireLong() {
        if (type != Type.INT) throw new IllegalStateException("Expected INT, got " + type);
        return intValue;
    }
    
    public double requireDouble() {
        if (type != Type.DOUBLE) throw new IllegalStateException("Expected DOUBLE, got " + type);
        return doubleValue;
    }
}
```

## Фаза 5: Helper — Variant из ValueResponse

**Новый helper-метод** (добавить в `FastCacheAsyncSimpleClient` или `KeyValueUtils`):

```java
private Variant toVariant(ValueResponse resp) {
    if (!resp.hasValueUnordered()) return Variant.none();
    Value val = resp.getValueUnordered();
    ValueType vt = val.hasValueType() ? val.getValueType() : ValueType.AUTO;
    BinaryPayload bp = val.getValue();
    
    // Handle compression
    ByteString rawBytes = extractBinaryFromPayload(bp, vt);
    
    switch (vt) {
        case INT:
            return Variant.ofInt(bp.getIntPayload());
        case DOUBLE:
            return Variant.ofDouble(bp.getDoublePayload());
        case BYTES:
        case AUTO:
        default:
            // For AUTO/BYTES, check which oneof field is set
            if (bp.hasIntPayload()) return Variant.ofInt(bp.getIntPayload());
            if (bp.hasDoublePayload()) return Variant.ofDouble(bp.getDoublePayload());
            if (bp.hasPayload()) return Variant.ofBytes(bp.getPayload().toByteArray());
            return Variant.none();
    }
}

private ByteString extractBinaryFromPayload(BinaryPayload bp, ValueType vt) {
    switch (vt) {
        case INT:
            return ByteString.copyFrom(Long.toByteArray(bp.getIntPayload()));
        case DOUBLE:
            return ByteString.copyFrom(Long.toByteArray(Double.doubleToLongBits(bp.getDoublePayload())));
        case BYTES:
        case AUTO:
        default:
            return bp.hasPayload() ? bp.getPayload() : ByteString.EMPTY;
    }
}
```

```java
private CreateRequest buildAtomicCreateRequest(byte[] key, KeyHintData hint, long value, Duration ttl, int clientId) {
    CreateRequest.Builder builder = CreateRequest.newBuilder()
        .setKey(buildKey(key, hint, clientId))
        .setValue(Value.newBuilder()
            .setValue(BinaryPayload.newBuilder().setIntPayload(value))
            .setValueType(ValueType.INT)
            .build());
    if (ttl != null && !ttl.isZero()) {
        builder = builder.toBuilder()
            .setValue(builder.getValue().toBuilder()
                .setTtl(System.currentTimeMillis() + ttl.toMillis()));
    }
    return builder.build();
}
```
