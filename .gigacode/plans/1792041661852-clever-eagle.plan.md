# Standalone Simple Tests Plan

## Overview
Переписываем все standalone/simple тесты с нуля для покрытия нового Variant API.
Каждый контейнер — отдельный файл. Все тесты наследуются от `TestBase`.

**Цель покрытия: 80%+ методов из proto-файла**

---

## Базовые хелперы (TestBase)
```java
Variant v(String val) → Variant.ofBytes(val.getBytes())
Variant v(byte[] val) → Variant.ofBytes(val)
Variant vi(int val) → Variant.ofInt(val)
Variant vd(double val) → Variant.ofDouble(val)
Payload p(String val) → Payload.of(val.getBytes())
Payload p(byte[] val) → Payload.of(val)
String str(Variant v) → new String(v.bytesValue())
byte[] bytes(String val) → val.getBytes()
```

## 1. ScalarOperationsTest.java (SCALAR VALUE)

### Методы из proto:
- `createKeyValue(CreateRequest)` → KeyHintResponse
- `getValue(GetRequest)` → ValueResponse
- `getAndDeleteValue(GetRequest)` → ValueResponse
- `existKey(GetRequest)` → BoolResponse
- `updateValue(UpdateRequest)` → UpdateValueResponse
- `remove(GetRequest)` → BoolResponse
- `setTtl(TtlRequest)` → BoolResponse
- `getTtl(GetRequest)` → TtlResponse

### 1.1 Create + Read
- `createKeyValue(key, Variant.ofBytes(...))` → `getValue(key)` → bytesValue()
- `createKeyValue(key, Variant.ofInt(...))` → `getValue(key)` → intValue()
- `createKeyValue(key, Variant.ofDouble(...))` → `getValue(key)` → doubleValue()

### 1.2 Type Switching
- bytes → int: `updateKeyValue(key, Variant.ofInt(42))` → `getValue(key).intValue()`
- int → double: `updateKeyValue(key, Variant.ofDouble(3.14))` → `getValue(key).doubleValue()`
- double → bytes: `updateKeyValue(key, Variant.ofBytes("new"))` → `getValue(key).bytesValue()`

### 1.3 GetAndDelete
- `getAndDeleteValue(key)` → Variant → проверка типа
- Повторный `getValue(key)` → NOT_FOUND

### 1.4 Exist + Remove
- `existKey(key)` → true
- `remove(key)` → true
- `existKey(key)` после remove → false

### 1.5 TTL
- `setTtl(key, ttl)` → `getTtl(key)` → проверка
- TTL expiration → NOT_FOUND

### 1.6 Locks
- READ_LOCK: owner read OK, intruder denied
- WRITE_LOCK: owner read/write OK, intruder denied
- GLOBAL: only owner
- Unlock by owner only
- Lock expiration

### 9.1 Create + Read
- `createKeyValue(key, Variant.ofInt(n))` → `getValue(key)` → intValue()
- `createKeyValue(key, Variant.ofDouble(n))` → `getValue(key)` → doubleValue()

### 9.2 Atomic Operations (int)
- `atomicAdd(key, delta)` → Number
- `atomicSub(key, delta)` → Number
- `atomicAnd(key, mask)` → Long
- `atomicOr(key, mask)` → Long
- `atomicXor(key, mask)` → Long
- `atomicExchange(key, value)` → Number
- `atomicCompareAndSet(key, expected, new)` → AtomicCasRes

### 9.3 Atomic Operations (double)
- `atomicAdd(key, delta)` на double → Number
- `atomicSub(key, delta)` на double → Number
- `atomicExchange(key, value)` на double → Number

### 9.4 Edge Cases
- Overflow: `atomicAdd(Long.MAX_VALUE, 1)` → OUT_OF_RANGE
- Underflow: `atomicSub(10, 50)` → negative
- CAS success/failure

### 9.5 Type Switching
- `createKeyValue(key, Variant.ofInt(100))` → `atomicAdd(key, 50)` → 150
- `createKeyValue(key, Variant.ofDouble(10.5))` → `atomicAdd(key, 5.0)` → 15.5

### 9.6 Locks
- READ_LOCK: read OK, write denied
- WRITE_LOCK: owner read/write OK, intruder denied
- GLOBAL: only owner
- Lock expiration
