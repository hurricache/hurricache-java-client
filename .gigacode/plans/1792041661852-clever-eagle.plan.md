# Stress Tests Plan

## Overview
Create stress tests for all HurriCache operations in `/ext/hurricache-java-client/src/test/java/com/hurricache/client/cluster/stress/`.

## Test Structure
- Each stress test extends `TestBaseCluster`
- Tests measure operations per second (OPS)
- Tests fill containers before benchmarking if needed
- All tests use `client` from TestBaseCluster

## Configurable Parameters (static final в каждом тесте)
| Параметр | Default | Описание |
|----------|---------|----------|
| `WARMUP_ITERATIONS` | 1000 | Итераций warmup фазы |
| `BENCHMARK_ITERATIONS` | 10000 | Итераций benchmark фазы |
| `THREAD_COUNT` | 1 | Количество потоков (1 = single-threaded) |
| `CONTAINER_SIZE` | 1000 | Размер контейнера для заполнения (10000 для queue/list/vector) |

## Stress Test Template

```java
public class SmartClientScalarStressTest extends TestBaseCluster {
    
    // ====== CONFIGURABLE PARAMETERS ======
    private static final int WARMUP_ITERATIONS = 1000;      // warmup итерации
    private static final int BENCHMARK_ITERATIONS = 10000;  // benchmark итерации
    private static final int THREAD_COUNT = 1;              // 1 = single-threaded
    
    @Test
    @DisplayName("Stress test: get")
    void stressTestGet() throws Exception {
        // 1. Setup
        String key = "stress_get_" + UUID.randomUUID();
        client.create(key, v("value")).get();
        KeyHintData hint = client.get(key).get().getHint();
        
        // 2. Warmup
        for (int i = 0; i < WARMUP_ITERATIONS; i++) {
            client.get(key, hint, getDefaultClientId()).get();
        }
        
        // 3. Benchmark (single-threaded)
        long startTime = System.nanoTime();
        for (int i = 0; i < BENCHMARK_ITERATIONS; i++) {
            client.get(key, hint, getDefaultClientId()).get();
        }
        long endTime = System.nanoTime();
        
        // 4. Results
        double elapsed = (endTime - startTime) / 1_000_000_000.0;
        double ops = BENCHMARK_ITERATIONS / elapsed;
        System.out.printf("[Get] %d iters, %.3fs, %.2f OPS%n",
                         BENCHMARK_ITERATIONS, elapsed, ops);
    }
    
    // ====== MULTI-THREADED TEMPLATE ======
    @Test
    @DisplayName("Stress test: get (multi-threaded)")
    void stressTestGetMultiThreaded() throws Exception {
        if (THREAD_COUNT <= 1) return; // Skip if single-threaded
        
        String key = "stress_get_mt_" + UUID.randomUUID();
        client.create(key, v("value")).get();
        KeyHintData hint = client.get(key).get().getHint();
        
        int warmupIters = WARMUP_ITERATIONS / THREAD_COUNT;
        int benchmarkIters = BENCHMARK_ITERATIONS / THREAD_COUNT;
        
        // Warmup
        List<Thread> warmupThreads = new ArrayList<>();
        for (int t = 0; t < THREAD_COUNT; t++) {
            Thread wt = new Thread(() -> {
                for (int i = 0; i < warmupIters; i++) {
                    try { client.get(key, hint, getDefaultClientId()).get(); }
                    catch (Exception e) { /* ignore */ }
                }
            });
            warmupThreads.add(wt);
            wt.start();
        }
        for (Thread wt : warmupThreads) wt.join();
        
        // Benchmark
        CountDownLatch startLatch = new CountDownLatch(1);
        CountDownLatch doneLatch = new CountDownLatch(THREAD_COUNT);
        AtomicLong totalErrors = new AtomicLong(0);
        
        List<Thread> benchmarkThreads = new ArrayList<>();
        long startTime = System.nanoTime();
        
        for (int t = 0; t < THREAD_COUNT; t++) {
            Thread bt = new Thread(() -> {
                try { startLatch.await(); }
                catch (InterruptedException e) { Thread.currentThread().interrupt(); }
                for (int i = 0; i < benchmarkIters; i++) {
                    try { client.get(key, hint, getDefaultClientId()).get(); }
                    catch (Exception e) { totalErrors.incrementAndGet(); }
                }
                doneLatch.countDown();
            });
            benchmarkThreads.add(bt);
            bt.start();
        }
        
        startLatch.countDown(); // Start all threads simultaneously
        doneLatch.await();
        long endTime = System.nanoTime();
        
        double elapsed = (endTime - startTime) / 1_000_000_000.0;
        double ops = BENCHMARK_ITERATIONS / elapsed;
        System.out.printf("[Get MT] %d iters x %d threads, %.3fs, %.2f OPS, %d errors%n",
                         benchmarkIters, THREAD_COUNT, elapsed, ops, totalErrors.get());
    }
}
```

## HIGH-PERFORMANCE Containers Template (Queue/List/Vector)
```java
public class SmartClientQueueStressTest extends TestBaseCluster {
    
    // ====== CONFIGURABLE PARAMETERS ======
    private static final int WARMUP_ITERATIONS = 10000;     // warmup итерации
    private static final int BENCHMARK_ITERATIONS = 100000; // benchmark итерации
    private static final int THREAD_COUNT = 1;              // 1 = single-threaded
    private static final int CONTAINER_SIZE = 10000;        // элементов в очереди
    
    @Test
    @DisplayName("Stress test: peekHead")
    void stressTestPeekHead() throws Exception {
        // 1. Setup — fill queue with CONTAINER_SIZE elements
        String key = "stress_q_peek_" + UUID.randomUUID();
        List<Variant> initialData = new ArrayList<>();
        for (int i = 0; i < CONTAINER_SIZE; i++) {
            initialData.add(v("item_" + i));
        }
        KeyHintData hint = client.createQueue(key, initialData).get();
        
        // 2. Warmup
        for (int i = 0; i < WARMUP_ITERATIONS; i++) {
            client.peekHead(key, hint, getDefaultClientId()).get();
        }
        
        // 3. Benchmark
        long startTime = System.nanoTime();
        for (int i = 0; i < BENCHMARK_ITERATIONS; i++) {
            client.peekHead(key, hint, getDefaultClientId()).get();
        }
        long endTime = System.nanoTime();
        
        // 4. Results
        double elapsed = (endTime - startTime) / 1_000_000_000.0;
        double ops = BENCHMARK_ITERATIONS / elapsed;
        System.out.printf("[Queue.peekHead] size=%d, %d iters, %.3fs, %.2f OPS%n",
                         CONTAINER_SIZE, BENCHMARK_ITERATIONS, elapsed, ops);
    }
}

## Key Requirements
1. **All parameters configurable** via `static final` constants at top of each test class:
   - `WARMUP_ITERATIONS` — warmup фазы (default: 1000)
   - `BENCHMARK_ITERATIONS` — benchmark фазы (default: 10000)
   - `THREAD_COUNT` — количество потоков (default: 1, single-threaded)
   - `CONTAINER_SIZE` — размер контейнера для заполнения (default: 1000, для queue/list/vector: 10000)
2. **Print results**: iterations, threads, elapsed time, OPS, errors
3. **Fill containers**: все контейнеры pre-filled с CONTAINER_SIZE элементами
4. **Use clientId**: все операции с clientId параметром
5. **Use hint**: все операции с KeyHintData
6. **Single-threaded** по умолчанию, **multi-threaded** опционально (пропускается если THREAD_COUNT=1)
