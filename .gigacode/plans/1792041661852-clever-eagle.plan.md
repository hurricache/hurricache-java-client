# SmartClient Routing Tests Plan

## Background

SmartClient routing tests verify that operations correctly route to MASTER/BACKUP nodes using KeyHintData, and that replication works properly across cluster nodes.

**Base class**: `TestBaseCluster` (`src/test/java/com/hurricache/TestBaseCluster.java`)
- Provides: `client` (FastCacheAsyncSmartClient), `v()`, `p()`, `str()`, `bytes()`, `createLargePayload()`, `createLargePayloadKey()`, `op()`, `assertDenied()`
- SmartClient connects to 3 coordinator nodes: `192.168.0.123:51000`, `:61000`, `:21000`

**SmartClient routing** (`src/main/java/com/hurricache/client/FastCacheAsyncSmartClient.java`):
- Uses `KeyHintData` (week_hash) for shard routing
- Modes: `MASTER`, `BACKUP`, `MASTER_THAN_BACKUP`, `LB_SMART`
- `repDelay()` = 500ms sleep for replication
- All operations route through `execute()` or `executeWrite()` using KeyHintData

**Existing pattern** (QueueOperationsTest):
```java
KeyHintData keyHint = client.setMode(Mode.MASTER).createQueue(key, data).get();
Thread.sleep(500); // replication pause
client.setMode(Mode.BACKUP).getHead(key, keyHint).get();
```

## Test File Structure

**Path**: `/ext/hurricache-java-client/src/test/java/com/hurricache/client/cluster/smart/SmartClientRoutingTest.java`

**Test scenarios** (following user's 2 patterns):

### Pattern 1: Create Object + Validate Replication
```
1. Create object (get KeyHintData from creation response) - NO setMode needed
2. Pause 500ms for replication
3. Verify on MASTER (exist/check) - setMode(Mode.MASTER)
4. Verify on BACKUP (exist/check) - setMode(Mode.BACKUP)
5. Read on MASTER - setMode(Mode.MASTER)
6. Read on BACKUP - setMode(Mode.BACKUP)
```

### Pattern 2: Modify on Master + Validate Replication
```
1. Make modification operation on MASTER - setMode(Mode.MASTER)
2. Pause 500ms for replication
3. Verify operation on BACKUP - setMode(Mode.BACKUP)
4. Read on MASTER - setMode(Mode.MASTER)
5. Read on BACKUP - setMode(Mode.BACKUP)
```

## Key Implementation Details

1. **Always use KeyHintData** from creation response in subsequent operations
2. **Use `client.setMode(Mode.MASTER/BACKUP)`** before each operation
3. **500ms pause** after create/modify for replication
4. **Validate on both nodes** - master and backup
5. **Use byte[] keys** via `createLargePayloadKey()` for realistic testing
6. **Use `v()` helper** for Variant creation
7. **No @Disabled annotations**
