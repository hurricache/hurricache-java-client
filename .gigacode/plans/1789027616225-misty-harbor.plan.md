# Plan: Comprehensive List Container Test Class

## Objective
Create a comprehensive test class for **List** container operations (`createList`) at:
`/ext/hurricache-java-client/src/test/java/com/hurricache/client/standalone/simple/ListOperationsTest.java`

The class will be organized similarly to `VectorOperationsTest.java` but use `createList`/`streamList` and cover all required operations with missing edge cases.

## Current Coverage Analysis

**Existing List tests (minimal):**
- `AdvancedCollectionsTest.java`: 1 test (head + positional add)
- `RelativePositionOperationsTest.java`: 3 tests (positionBefore, positionAfter, missing pivot)

**Missing from List tests (compared to VectorOperationsTest.java):**
- Lock/unlock tests for List
- TTL tests for List
- Error cases (NOT_FOUND) for List operations
- Edge cases (empty list, boundary indices, negative indices)
- Most List-specific operations not tested at all

## Key Differences from VectorOperationsTest.java

1. **All operations use `createList`/`streamList` instead of `createVector`/`streamVector`**
2. **`streamElementInRangeUnordered` uses `ContainerType.LIST` instead of `ContainerType.VECTOR`**
3. **Additional edge cases not in Vector tests:**
   - Single-element list operations (empty after removal, head==tail)
   - Position boundary tests (position 0, position == size)
   - Insert before first/after last element
   - Full range stream
4. **Additional lock coverage:**
   - READ_LOCK blocks ALL write operations (not just addElementToTail)
   - WRITE_LOCK blocks ALL read operations for others (not just getFront)
   - WRITE_LOCK blocks ALL write operations for others
5. **Additional error cases:**
   - More operations tested on missing lists
