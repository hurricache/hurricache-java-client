**Общий паттерн каждого теста (кроме empty):**
1. Создать вектор через `createVector` → получить `KeyHintData`
2. `Thread.sleep(500)` — ожидание репликации
3. **Write на MASTER** → `Thread.sleep(300)` → проверить результат на MASTER → `Thread.sleep(300)` → проверить результат на BACKUP
4. **Write на BACKUP** → `Thread.sleep(300)` → проверить результат на BACKUP → `Thread.sleep(300)` → проверить результат на MASTER

**Для lock/setTtl:**
- Установить TTL/lock на MASTER → `Thread.sleep(300)` → проверить на MASTER → `Thread.sleep(300)` → проверить на BACKUP
- Установить TTL/lock на BACKUP → `Thread.sleep(300)` → проверить на BACKUP → `Thread.sleep(300)` → проверить на MASTER

**Для lock/TTL expiration:**
- Установить lock/TTL с коротким временем на MASTER → ждать истечения → проверить MASTER+BACKUP
- Установить lock/TTL с коротким временем на BACKUP → ждать истечения → проверить BACKUP+MASTER

## 5. Ключевые конвенции

### Паттерн репликации (для всех тестов кроме empty):
```java
// 1. Создать на MASTER
KeyHintData keyHint = client.setMode(Mode.MASTER)
    .createVector(key, payloads).get();
Thread.sleep(500); // начальная репликация

// 2. Write на BACKUP → задержка → проверить BACKUP → задержка → проверить MASTER
client.setMode(Mode.BACKUP).operation(...).get();
Thread.sleep(300); // задержка репликации
// Assert на BACKUP
Thread.sleep(300); // задержка репликации на MASTER
// Assert на MASTER

// 3. Write на MASTER → задержка → проверить MASTER → задержка → проверить BACKUP
client.setMode(Mode.MASTER).operation(...).get();
Thread.sleep(300); // задержка репликации
// Assert на MASTER
Thread.sleep(300); // задержка репликации на BACKUP
// Assert на BACKUP
```

### Паттерн для lock/setTtl с репликацией:
```java
// 1. Создать на MASTER
KeyHintData keyHint = client.setMode(Mode.MASTER)
    .createVector(key, payloads).get();
Thread.sleep(500); // начальная репликация

// 2. Set на BACKUP → задержка → проверить на BACKUP → задержка → проверить на MASTER
client.setMode(Mode.BACKUP).setTtl(key, keyHint, ttl, clientId).get();
Thread.sleep(300); // задержка репликации
// Assert на BACKUP
Thread.sleep(300); // задержка репликации на MASTER
// Assert на MASTER

// 3. Set на MASTER → задержка → проверить на MASTER → задержка → проверить на BACKUP
client.setMode(Mode.MASTER).setTtl(key, keyHint, ttl, clientId).get();
Thread.sleep(300); // задержка репликации
// Assert на MASTER
Thread.sleep(300); // задержка репликации на BACKUP
// Assert на BACKUP
```

### Паттерн для TTL/lock expiration:
```java
// Создать с коротким TTL (2s) на MASTER или BACKUP
KeyHintData keyHint = client.setMode(Mode.MASTER)
    .createVector(key, payloads, Duration.ofSeconds(2)).get();
Thread.sleep(500); // начальная репликация

// Проверить TTL/lock > 0 на обоих нодах
assertNotNull(client.getTtl(key, keyHint).get()); // MASTER
Thread.sleep(300); // задержка репликации
assertNotNull(client.getTtl(key, keyHint).get()); // BACKUP

// Подождать истечение TTL/lock
Thread.sleep(3000);

// Проверить NOT_FOUND/доступность на обоих нодах
assertNotFound(() -> client.getHead(key, keyHint).get()); // MASTER
Thread.sleep(300); // задержка репликации удаления
assertNotFound(() -> client.getHead(key, keyHint).get()); // BACKUP
```



### Обработка ошибок:
```java
// Для NOT_FOUND после удаления/TTL истечения
@Test
void assertNotFound(Runnable operation) {
    assertThrows(ExecutionException.class, () -> {
        operation.run();
    });
}
// Или:
try {
    client.getHead(key, keyHint).get();
    fail("Expected NOT_FOUND");
} catch (ExecutionException e) {
    StatusRuntimeException cause = (StatusRuntimeException) e.getCause();
    assertEquals(Status.Code.NOT_FOUND, cause.getStatus().getCode());
}
```

## 8. Примечания

- **Не удалять** существующие тесты в CollectionsTest, AdvancedCollectionsTest, RelativePositionOperationsTest
- `Thread.sleep` используется **только** для:
  - Ожидания репликации (500ms)
  - Ожидания TTL истечения (3000ms в testTtlExpirationOnMaster/OnBackup)
  - Ожидания lock истечения (3000ms в testLockExpirationOnMaster/OnBackup)
- Все lock-методы используют `clientId` параметр
- Для lock-тестов: READ_LOCK разрешает параллельные чтения, WRITE_LOCK запрещает всё кроме владельца, GLOBAL блокирует всех кроме владельца
- `unlockObject` только владелец может разблокировать, остальные получают `LockStatus.CANT_UNLOCK`
- Вектор создается через `createVector`, KeyHintData берется из результата create
